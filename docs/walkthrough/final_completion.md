## 告別展示品：六大真實實作改革

### 1. 拒絕假還原：完整的 IndexedDB 本機專案庫
* **解決的問題**：原先從近期清單切換專案時，若不是當前專案會被空白範本覆蓋。
* **真實實作**：將所有專案的全部檔案與修改歷程持久化儲存於 IndexedDB，跨專案切換、重啟瀏覽器均能 100% 完整還原現場。

### 2. 拒絕單檔玩具：Chromebook 本機實體資料夾連動
* **真實實作**：主頁新增「**開啟本機資料夾**」（W3C `showDirectoryPicker`），直接讀取學生 Chromebook 磁碟上的作業資料夾，編輯存檔直接寫回實體硬碟檔案。

### 3. 拒絕靜態假執行：Python 真正支援 `input()` 互動
* **真實實作**：在 Pyodide WebAssembly 核心掛載真實標準輸入（stdin），執行 `name = input(...)` 時會彈出輸入引導並串流回終端，初學者練習互動程式碼完全沒問題。

### 4. 拒絕死板日誌：終端 REPL 即時求值列
* **真實實作**：輸出抽屜底部配備互動命令行，可直接在終端輸入 JavaScript 或 Python 表達式進行即時求值與驗證。

### 5. 拒絕陽春 prompt 彈窗：現代行內新建與 F2 就地改名
* **真實實作**：點擊 `+ 新增` 或雙擊檔案名稱（或按 `F2`），直接在檔案列表內原地呼叫輸入框，按 `Enter` 完成，按 `Esc` 取消；並提供右鍵專屬選單。

### 6. 拒絕窄版預覽：一鍵於新分頁展開網頁
* **真實實作**：建置網頁後，可點擊「新分頁開啟」在全螢幕獨立視窗中檢視與除錯。
