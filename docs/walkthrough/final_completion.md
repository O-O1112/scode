## 告別展示品：八大正式實作功能

### 1. 模式 B：極簡單檔模式（拒絕預設展示檔案）
* **實作細節**：建立新專案時，不預先塞入任何展示用程式碼或示範檔（如 `README.md`、`style.css`、`app.js` 等），僅建立單一 0 位元組空白入口檔案（HTML 建立 `index.html`、Python 建立 `main.py`、Lua 建立 `main.lua`、JS 建立 `index.js`），提供使用者 100% 乾淨的起點。

### 2. 未儲存狀態提示點（Dirty State ●）與 Ctrl+W 關閉分頁
* **實作細節**：
  * Monaco 編輯器內容變更時，分頁標籤即時顯示圓點標記 `●`。
  * 按下 `Ctrl + S` 儲存後立即清除未儲存標記。
  * 支援點選分頁叉號或按下 `Ctrl + W` 關閉當前分頁。
  * 分頁全數關閉時，主編輯區呈現優雅的「無開啟檔案」極簡深色占位引導。

### 3. 完整 IndexedDB 本機專案庫（非空殼範本還原）
* **實作細節**：將所有專案的全部檔案與修改歷程持久化儲存於 IndexedDB，跨專案切換、重啟瀏覽器均能 100% 完整還原現場；首頁並提供本機專案數量與容量（KB）統計。

### 4. Chromebook 本機實體資料夾雙向連動
* **實作細節**：主頁「**開啟本機資料夾**」（W3C `showDirectoryPicker`），直接讀取學生 Chromebook 磁碟上的作業資料夾，編輯存檔直接寫回實體硬碟檔案。

### 5. Python (WASM) 真正支援 `input()` 互動
* **實作細節**：在 Pyodide WebAssembly 核心掛載真實標準輸入（stdin hook），執行 `name = input(...)` 時彈出輸入引導並串流回終端，初學者練習互動程式碼免裝環境。

### 6. 終端 REPL 即時求值列
* **實作細節**：輸出抽屜底部配備互動命令行，可直接在終端輸入 JavaScript 或 Python 表達式進行即時求值與驗證。

### 7. 現代行內新建與 F2 就地改名（自訂黑白選單）
* **實作細節**：點擊 `+ 新增` 或雙擊檔案名稱（或按 `F2`），直接在檔案列表內原地呼叫輸入框，按 `Enter` 完成，按 `Esc` 取消；並提供自訂純黑白右鍵選單。

### 8. 正式版關於彈窗（About Modal）與開源資訊
* **實作細節**：首頁新增 GitHub 倉庫按鈕與「關於」按鈕，呼叫包含版本號 (v1.2.0)、MIT 開源授權、完全本機離線隱私承諾與 GitHub 連結之彈窗。
