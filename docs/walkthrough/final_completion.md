## 完備升級模組清單

| 模組 | 升級前狀態 | 最終完備版狀態 |
| :--- | :--- | :--- |
| **檔案樹管理** | 僅支援新增與刪除 | 支援**雙擊改名**、**單檔獨立下載**、**檔案刪除**與**本機檔案拖曳匯入 (Drag & Drop)** |
| **偏好設定中心** | 無設定介面 | 支援**字級大小 (12-20px)**、**縮排寬度 (2/4 空格)**、**自動折行**、**代碼縮圖切換**、**代碼一鍵格式化**與**快取重置** |
| **建置輸出抽屜** | 固定高度、混雜畫面 | 支援**日誌與預覽分頁切換**、**全螢幕放大 (Maximize)**、**毫秒級執行計時 (Elapsed Time)** |
| **PWA 安裝** | 僅靜態 Manifest 宣告 | 整合原生 `beforeinstallprompt` 事件，主頁動態呈現「**安裝至本機**」按鈕 |
| **核心載入體驗** | 無載入提示 | 內建純黑極簡載入遮罩，Monaco 初始化完成後平滑淡出 |
| **發布與部署** | 需手動設定託管平台 | 內建 `.github/workflows/deploy.yml`，推送到 GitHub 即可透過 GitHub Actions 自動上架 |
