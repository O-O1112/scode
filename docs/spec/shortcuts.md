# MonoCode 全域快捷鍵規範

| 快捷鍵 | 作用範圍 | 功能說明 |
| :--- | :--- | :--- |
| `Ctrl + S` / `Cmd + S` | 工作區 | 儲存當前編輯中檔案（優先寫入本機檔案控制代碼） |
| `Ctrl + O` / `Cmd + O` | 全域 | 開啟本機檔案並載入工作區 |
| `Ctrl + Enter` | 工作區 | 觸發目前專案的「建置與執行」流程 |
| `Ctrl + B` | 工作區 | 切換左側檔案導覽面板（顯示 / 隱藏） |
| `F1` | 全域 | 開啟 / 關閉快捷鍵指南模態視窗 |
| `Escape` | 全域 | 關閉任何已開啟的模態視窗 |
